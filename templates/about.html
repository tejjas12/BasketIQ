What is BASKET IQ?

BASKET IQ is an AI-powered retail recommendation and Market Basket Analysis application designed to discover relationships between products purchased together. It analyses historical grocery transactions and converts raw purchase records into interpretable product associations.

The system uses the Apriori algorithm, an unsupervised association rule mining technique, to identify frequent itemsets. It then generates directional association rules evaluated using Support, Confidence and Lift.

These discovered rules form the foundation of the recommendation interface. A user can select products in a shopping basket and receive suggestions based on matching historical association rules.

The application combines data preprocessing, machine learning, backend processing and interactive visualisation into one integrated web-based retail analytics system.

THE PROBLEM

Finding Hidden Purchase Patterns

Retail transaction datasets contain large volumes of records describing customer purchases. Although these records provide valuable information, manually identifying which products frequently occur together can be difficult and time-consuming.

Without a systematic analysis method, useful relationships between products may remain hidden inside transaction data. BASKET IQ addresses this challenge by applying association rule mining to discover recurring product combinations.

CORE MINING ALGORITHM

What is the Apriori Algorithm?

Apriori is an association rule mining algorithm used to discover frequent itemsets in transactional databases. It works by examining item combinations and eliminating candidate combinations that cannot satisfy the minimum support requirement.

∞
The Apriori Principle

If an itemset is frequent, all of its non-empty subsets must also be frequent. Conversely, if an itemset is infrequent, its supersets cannot be frequent.

Three Important Evaluation Metrics

These metrics help evaluate the discovered association rules.

S METRIC 01

Support

Measures the proportion of all transactions that contain both A and B.

Support(A → B)
= Count(A ∪ B) / N
Indicates how frequently the product combination occurs.
C METRIC 02

Confidence

Measures how frequently B appears in transactions that contain A.

Confidence(A → B)
= Support(A ∪ B) / Support(A)
Indicates the conditional frequency of B given A.
L METRIC 03

Lift

Compares the rule confidence with the overall support of the consequent B.

Lift(A → B)
= Confidence(A → B) / Support(B)
Indicates the strength of association relative to independent occurrence.

Understanding Lift Values

Lift > 1Positive association
Lift = 1Independent occurrence
Lift < 1Negative association
Important distinction: Association rules identify statistical relationships in historical transactions. They do not establish causation or guarantee that a customer will purchase a recommended product.

APPLICATION LOGIC / 08

How Recommendations Are Generated

Connecting selected basket items with discovered association rules.

08
✧

From Selected Products to Suggestions

The recommendation engine uses the association rules discovered during the Apriori mining process. It matches the selected products against rule antecedents and returns eligible consequent products.

01 Product Selection User selects products
02 Basket Creation Selected items form a basket
03 Rule Matching Match basket with antecedents
04 Rule Ranking Rank matching rules
05 Suggestions Display eligible products
Antecedent Matching

The selected basket must contain all products in a rule's antecedent.

Consequent Filtering

Products already present in the selected basket are excluded from suggestions.

Rule Ranking

Matching rules are ranked using lift, confidence and support.

Recommendations are generated from the available association rules. If no rule matches the selected basket, the system may return no recommendations.
